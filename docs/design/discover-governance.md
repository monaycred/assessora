# Descobrir — regras de publicação

## Conteúdo
- Dicas
- Filmes e séries
- Cursos gratuitos
- Eventos

## Permissões
- Todos os usuários aprovados podem sugerir conteúdo.
- Sugestão nunca é publicada automaticamente.
- Administradores revisam título, descrição, link, categoria, imagem, data e gratuidade.
- Administrador pode aprovar, editar, recusar, retirar do ar ou destacar.
- Criadores de grupos publicam diretamente apenas no feed dos próprios grupos, conforme suas permissões; isso não publica no Descobrir.

## Fluxo
1. Usuário toca em Sugerir conteúdo.
2. Informa tipo, título, link, descrição e, se aplicável, data/local.
3. Item fica pendente.
4. Administrador recebe aviso e revisa.
5. Usuário recebe o resultado da análise.

## Padrão visual
Sem frases manuscritas genéricas. Cada espaço apresenta apenas informações úteis para decisão.
